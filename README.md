# RepairRadar

AI-Based Predictive Maintenance System

## Run in VS Code

1. Install Python 3.10 or newer.
2. Open this folder in VS Code.
3. Open the terminal.
4. Run: pip install -r requirements.txt
5. Check that `dataset/repairradar_synthetic.csv` and both trained models in `models/` are present.
6. Run: streamlit run app.py

The app also supports the `artifacts/` layout produced by the notebook. If that folder is
present, its saved files take precedence. The notebook is available in the notebooks folder.
